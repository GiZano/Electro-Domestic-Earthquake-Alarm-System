## 3. CI workflow: `.github/workflows/deploy-gh-pages.yml`

Sync `docs/web/` → `GiZano/GiZano.github.io` on changes.

- Trigger:
  ```yaml
  on:
    push:
      branches: ["main"]
      paths: ["docs/web/**", ".github/workflows/deploy-gh-pages.yml"]
    workflow_dispatch:
  ```
- Job `sync-pages`:
  1. `actions/checkout` this repo.
  2. Clone `GiZano/GiZano.github.io` (ref `main`) using the PAT.
  3. Copy files per the table in step 1 (html/css/js/demo.js + `assets/`).
  4. `git add` + `git commit` (skip if nothing changed) + `git push`.

### Secret requirement
- **`GIZANO_IO_PAT`** — fine-grained PAT on `GiZano/GiZano.github.io`
  (`Contents: Read and write`). The repo-default `GITHUB_TOKEN` cannot write to
  another repository.
- Add the secret at
  `https://github.com/GiZano/QuakeGuard/settings/secrets/actions`.
