## Overview
This PR completes the `v2.0.0` QuakeGuard milestone by introducing the "Zero-Config" orchestration pipeline (`generate_secrets.sh` and `quakeguard_init.sh`) and ensuring 100% CI/CD coverage across all project features. It also scrubs all lingering references to older architecture versions (v1.2.x, v1.3.0), unifying the entire codebase under the v2.0.0 release standard and translating residual Italian comments to English.

## Changes Made
* **DevOps Automation (`scripts/`)**: Created `quakeguard_init.sh` and `generate_secrets.sh` to automatically generate, synchronize, and handle cryptographic keys (256-bit) and dynamic Cloudflare tunnels across backend, mobile, and firmware with intelligent conflict resolution. Added CI safety switch (`CI=true`).
* **CI/CD Pipelines (`.github/workflows/`)**: 
  - Added TypeScript static checking (`npx tsc --noEmit`) to the Mobile CI pipeline.
  - Automated Typst PDF compilation and auto-deploy in the `deploy-gh-pages.yml` pipeline.
  - Added script execution testing for `generate_secrets.sh` in the DevOps CI.
* **Backend Mathematics (`backend/tests/unit/test_triangulation.py`)**: Authored missing unit tests covering `triangulate_epicenter`, Haversine distance, magnitude-weighted centroid estimation, and P-wave origin time.
* **Documentation (`docs/whitepaper/`)**: Wrote Chapter 09 (`09-devops.typ`) covering DevOps strategy. Fixed Typst numbering bugs and translated structural comments.
* **Global Refactor**: Scrubbed all `v1.2.x` and `v1.3.0` strings across the repository (C++, Python, React Native, YAML) up to `v2.0.0` and translated Italian code comments to English.

## Impact & Next Steps
This firmly locks the repository for the `v2.0.0` release. Any new developer or CI runner can now clone the repository and run `./scripts/quakeguard_init.sh` to get an instant, perfectly configured full-stack environment without manually touching `.env` files. Future work will focus on integrating edge-AI (v2.2.0).
